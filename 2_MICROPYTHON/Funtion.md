# 🤖 YOLO ESP32

Proyecto de **MicroPython y YOLO para ESP32**, desarrollado para la asignatura de Microcontroladores.

## 📁 Contenido

- `2_MICROPYTHON/` → Código desarrollado en MicroPython para el ESP32.
- `YOLO.py` → Código relacionado con YOLO.
- `README.md` → Documentación del proyecto.

## 🔧 Tecnologías

- ESP32
- MicroPython
- Python
- YOLO
- Git / GitHub

## ⚡ MicroPython

El código implementa:

- Tareas concurrentes.
- Interrupciones para los botones.
- Control de LEDs.
- Cola de datos entre tareas.

### 📌 Pines

| Componente | GPIO |
|------------|------|
| 🔘 Botón 1 | 13 |
| 🔘 Botón 2 | 14 |
| 💡 LED 1 | 25 |
| 💡 LED 2 | 26 |
